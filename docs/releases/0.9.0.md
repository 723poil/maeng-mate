### 새로운 기능

- 수집 소스마다 분류에 사용할 원본 칼럼을 고르고, 상태와 우선순위처럼 여러 칼럼의 값을 조합해 분류할 수 있습니다. 규칙마다 ‘모두 일치’ 또는 ‘하나라도 일치’를 선택하고, 여러 규칙에 해당하면 위에 놓은 규칙을 먼저 적용합니다. 기존 업무·QA 완료 상태, 일정 유형, 휴가 승인값과 카테고리에서 설정한 분류도 해당 소스에서 확인하고 편집할 수 있습니다.
- AI에 “내 미완료 업무 찾아줘”라고 요청하면 표마다 어떤 상태가 있는지 먼저 확인할 수 있습니다. 업무 표의 ‘진행 중’과 QA 표의 ‘검수 대기’처럼 각 표에서 원하는 상태를 골라 검색할 수 있습니다.
- 상태를 여러 개 지정하거나 상태가 비어 있는 업무만 따로 찾을 수 있습니다. 원본 상태 목록에는 다음 정상 수집부터 아직 업무에 쓰이지 않은 선택지도 표시됩니다.
- 업무를 검색할 때 직접 만든 카테고리를 지정하면 그 카테고리에 연결한 여러 표에서 본인 업무를 함께 찾을 수 있습니다.
- 부모 항목 안의 하위 표를 수집할 때 부모 제목 표시와 정렬값을 따로 설정할 수 있습니다. 부모 표의 숫자 칼럼을 연결하거나 ‘2026년 12차’에서 차수 12를 읽을 수 있습니다.

### 개선 사항

- 소스 연결 편집은 ‘수집에 사용할 속성’에서 시작합니다. 이어서 ‘분류 기준’과 ‘카테고리 칼럼 연결’을 설정할 수 있습니다.
- MCP의 개인 업무 조회와 검색에는 메뉴바에서 숨긴 QA나 오래된 완료 업무도 포함됩니다. 본인 담당 범위는 그대로 유지됩니다.
- 캘린더는 수집 중이거나 수집에 실패해도 마지막으로 확인한 일정 목록을 재사용합니다. 새 일정은 수집에 성공한 뒤 다음 조회부터 표시됩니다.

### 오류 수정

- 업무 카드가 수집 소스에서 정한 분류와 카드에 지정한 순서로 정렬됩니다. 업데이트하면 기존 상태 그룹을 소스별 분류 규칙에서 확인하고 편집할 수 있습니다.
- 캘린더에서 날짜를 선택하면 상세 목록에도 메인 목록과 같은 상태 배지가 표시됩니다. 이전에는 표시 칼럼을 직접 선택하면 상태가 일반 텍스트로만 보였습니다.
- 부모 정렬에 연결한 숫자 칼럼의 이름이나 타입이 바뀌면 설정에 누락된 칼럼 이름을 표시합니다. 다른 설정을 저장해도 연결이 유지되고, 정렬을 바꾸거나 해제한 뒤 같은 표를 처음 조회해도 방금 선택한 값이 유지됩니다.
- 메뉴바에서 기한이 있거나 표시 칼럼을 직접 고른 업무에도 부모 제목이 표시됩니다. 긴 부모 제목은 줄여서 업무 제목을 읽을 공간을 확보하고, 전체 부모 제목은 도움말에 표시합니다.
- QA에서 부모 제목 표시를 켜고 정렬 방식을 바꿔도 차시 필터와 완료 차시 숨김 규칙이 유지됩니다. 이미 숨김이 풀렸다면 다음 정상 수집 후 다시 적용됩니다.
- 기존 업무 카드에서도 카드와 소스에 별도 정렬이 없으면 같은 하위 표의 12차 업무가 3차 업무보다 먼저 표시됩니다. 부모 정렬값이 빈 업무는 마지막에 표시됩니다.
