### 새로운 기능

- 알림 규칙을 열면 어떤 항목에, 언제, 어떤 문구를 어느 채널로 보낼지 한 창에서 정할 수 있습니다. 예를 들어 연결한 Notion 표의 ‘유형’이 ‘면접’인 항목에만 시작 10분 전 알림을 보낼 수 있습니다.
- 규칙을 만들 때 원본 표의 속성과 선택값을 고를 수 있습니다. 공통 저장 칼럼의 상태값은 최근 수집한 값에서 선택하거나 직접 입력할 수 있습니다.
- 알림 문구 아래에 현재 규칙에서 사용할 수 있는 변수가 표시됩니다. 변수를 클릭하면 커서 위치에 삽입되고, 발송할 때 항목 제목이나 수집 오류 안내 등 실제 내용이 들어갑니다.

### 개선 사항

- 기존 회의·일정 알림은 연결된 표의 유형과 날짜 조건으로 옮겨집니다. 기존 규칙을 열면 적용 중인 문구와 채널을 바로 확인하고 수정할 수 있습니다.
- 메뉴바와 달력에서 Notion 표에 입력한 일정 분류명을 확인할 수 있습니다.

### 오류 수정

- 설정의 버전 번호와 메뉴바 도움말에는 개발 앱에서만 ‘개발용’ 표시가 붙습니다.
- 표시 칼럼을 모두 숨겼을 때 메뉴바와 달력에 상태가 다시 나타나던 문제를 고쳤습니다.
- 수집할 표를 바꿀 때 이전 표의 칼럼 연결이나 상태 선택이 따라오던 문제와, QA 차시 제목 일부가 잘리던 문제를 고쳤습니다.
- 여러 표에 같은 종류의 알림이 있을 때 이전에 예약한 알림에 다른 표의 문구가 쓰일 수 있던 문제를 고쳤습니다.
