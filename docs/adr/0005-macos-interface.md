# ADR 0005. macOS 화면

상태: 채택

## 맥락

사용자가 메뉴바 한 화면에서 근무·수집·업무를 빠르게 조작하고, 설정에서는 표시와 전달을 독립적으로 관리한다.

## 결정

- 메뉴바 버튼은 펼친 수첩에 체크 표시를 넣은 단색 템플릿 아이콘 하나로 표시한다. macOS가 배경과 선택 상태에 맞춰 색을 정한다. 수집·연결 상태는 버튼 도움말, VoiceOver 이름과 패널의 수집 카드에서 확인한다.

- 카테고리의 `설정…` 시트는 저장 칼럼, 메인 목록, 캘린더, 알림 규칙을 나눠 표시한다. 캘린더 날짜와 알림에서 카테고리의 저장 칼럼을 고른다. 수집 소스의 `연결 편집` 시트는 카테고리의 값 종류와 호환되는 원본 속성을 보여 준다. 소스 연결의 적용은 저장 초안에 반영하고 취소는 이전 연결을 유지한다.
- 카테고리 설정 탭은 macOS 세그먼트 컨트롤로 전환한다. 알림 규칙 탭에는 등록한 이벤트 규칙과 칼럼 값 변경 규칙이 함께 나온다. 목록에서 선택한 규칙의 이름·조건·켜짐을 오른쪽에서 편집하며, 다른 규칙을 열기 전에 현재 입력을 검증한다.
- 메인 목록 탭은 표시 필터·숨김 조건·정렬 순서를 나눠 편집한다. 새 카드는 세 목록이 비어 있으며, 기존 카드에서 이전한 조건도 같은 행에서 수정하거나 삭제한다. 숨김 조건 중 하나라도 일치하는 행은 표시에서 제외한다. 필터는 선택한 칼럼의 값 종류에 맞는 연산자와 입력을 보여 준다. 정렬은 위에서부터 적용하며 행을 이동해 우선순위를 바꾼다. 규칙 모두 지우기도 저장 전까지는 편집 초안에만 적용한다.
- 소스 연결 시트도 세그먼트 컨트롤로 카테고리 칼럼과 수집에 사용할 속성을 전환한다. 저장 칼럼의 `추가 표시` 옆 물음표는 칼럼의 표시 위치와 숨긴 칼럼의 용도를 설명하고, `표시 예시` 라벨로 샘플을 구분한다.

- 테두리 없는 투명 `NSPanel`에 macOS 26 `NSGlassEffectView`를 직접 배치한다. 창 그림자·중첩 팝오버·별도 화살표를 없애고 콘텐츠 레이어의 배경과 모서리를 일치시킨다. 읽기 영역에는 외관에 맞는 불투명도 90%의 카드 바탕을 사용한다.
- 메뉴바 버튼을 기준으로 상단·좌우 위치를 고정한다. 목록 확대·축소 때 문서 높이를 바꾸고 읽던 위치를 보존한다. 높이만 바뀔 때는 기존 행을 위쪽에 고정해 재사용한다. 카드 순서는 전환 시작 때 정하고 애니메이션 프레임마다 재사용한다. 설정에서 숨긴 카드는 보관하고, 연결 소스가 사라진 카드는 뷰에서 제거한다. 각 행 버튼에 원본 링크를 연결하므로 다른 카드의 행 개수가 달라져도 링크 순번을 다시 매기지 않는다. 반복 조작·닫기·재열기 때 전환 상태를 정리한다. 움직임 줄이기를 지원한다. 목록 행은 상태·기한 또는 차시·제목을 한 줄에 표시하며 기본 순서는 업무→QA→회의다.
- 근무의 시·분·휴가는 한 줄에 두고 짧은 저장 상태를 퇴근 제목 옆에 표시한다. 긴 오류는 카드 상단에 표시한다. 새로고침·집계·주기 저장은 비동기로 진행 상태를 보여주며 기존 목록과 미저장 입력을 유지한다. 새로고침은 저장 자료를 다시 읽는다.
- 설정 사이드바와 창은 `SettingsPage`로 페이지를 식별한다. 일부 연동을 사용할 수 없어 목록 순서가 달라져도 재조회·저장·다시 시작은 선택된 페이지에 연결된다. 화면 표시·드래그 순서는 내부 정렬과 독립적이다. 전체 알림·각 채널·종류는 스위치로, 퇴근 시각은 복수 선택으로 관리한다. 설정의 조회 재시도는 단조 시계 기준 1초부터 최대 30초까지 대기를 늘린다. 메뉴바는 활성 설정 제어기 목록을 갱신·종료 대기·정리에 함께 사용한다. 초기 조회 실패는 재시도하지만 불명확한 저장·충돌은 초안을 유지한다.
- 시스템 글꼴의 실제 크기를 측정해 입력·행·배지를 가운데 맞춘다. 등록 배지는 공통 `SettingsBadge`와 `registration_status`를 사용한다. 등록 파랑·확인 초록·미등록 회색·실패 빨강·응답 지연과 요청 제한 주황으로 구분한다. 편집 키 조합은 현재 Cocoa 편집기에 전달하며 한글 입력 상태에서도 붙여넣기를 지원한다.

- 달력 월 이동은 백그라운드에서 조회하고 완료 신호를 메인 스레드에서 반영한다. 작은 달력과 별도 창은 요일 헤더와 42개 날짜 칸·버튼을 재사용한다. 월이나 필터가 바뀌면 날짜·일정·도움말을 갱신하고, 같은 월에서 날짜만 선택하면 선택 배경을 옮긴다. 대기 중에는 날짜 버튼만 잠그고, 숨은 격자는 다시 보일 때 갱신한다.

- 설정·출퇴근 창을 닫으면 주기적인 화면 갱신은 멈춘다. 진행 중인 저장·조회와 후속 설정 동기화는 마무리하고, 창을 다시 열 때 최신 결과와 초안을 표시한다.

## 결과와 검증

화면 영역을 숨겨도 수집·근무·알림 구독은 유지된다. `src/presentation/menubar.py`, `glass_panel.py`, `entry_section.py`, `preferences_window.py`를 기준으로 실제 앱에서 밝은·어두운 외관, 확대 재열기, 스크롤, 키 입력과 화면 경계를 확인한다.
