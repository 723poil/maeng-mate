## 오류 수정

- Notion과 Slack 연결 확인에서 잘못된 인증 정보, 설정 충돌, 일시적인 연결 장애를 구분하도록 오류 안내를 정리했습니다.
- 여러 알림이 대기할 때 알림마다 불필요하게 기다려 전달이 늦어지는 문제를 수정했습니다.
- 다른 프로그램이 앱의 통신 포트를 사용 중이면 시작을 중단하고, 저장된 설정·근무 기록·알림 예약을 변경하지 않도록 수정했습니다.
- 수동 수집 결과에서 이미 수집 중인 소스와 더 최신 자료가 저장되어 건너뛴 소스를 구분해 표시합니다.
- 개인 업무 검색 결과가 10만 건을 넘어도 MCP에서 마지막 페이지까지 이어서 조회할 수 있습니다.
- 개인 조회 응답의 크기를 실제 UTF-8 전송 바이트로 계산해, 한글이나 이모지가 포함된 결과가 용량 제한 안에서도 잘리거나 거절되던 문제를 수정했습니다.
- 개인 업무 검색에서 MCP와 HTTP가 같은 입력 형식을 확인합니다. 예를 들어 페이지 크기를 문자열로 보내면 입력 오류를 안내하고, 검색어로 입력한 `null`은 그대로 검색합니다.
- 검색 요청이 너무 크면 상태 이름의 수나 길이를 줄여 다시 검색하도록 안내합니다.
