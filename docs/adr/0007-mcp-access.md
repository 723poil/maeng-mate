# ADR 0007. 앱 내 MCP

상태: 채택

## 맥락

AI 앱에서 본인의 업무와 오늘 근무를 조회한다. AI 연결의 발급·만료·폐기를 앱에서 다루면서 관리 API는 분리한다.

## 결정

- FastMCP Streamable HTTP를 상주 API의 `/mcp/`에 연결하고 lifespan에서 세션 관리자를 시작·정리한다. stateless HTTP이므로 실행 여부와 최근 사용을 표시한다. 설정은 첫 조회 결과와 관리 작업 응답을 유지하며 최근 사용은 `다시 불러오기`로 갱신한다. 같은 목록을 표시하는 동안에는 다음 만료 시각에 도달하거나 시계가 이전 판정 시각보다 앞서면 표시 상태를 다시 확인한다. 만료 배지와 폐기 버튼의 잠금은 기존 행에서 갱신한다. stdio도 유지하며 조회 토큰과 선택 포트만 받아 로컬 API를 호출한다. 두 전송 방식은 같은 조회 포트와 서버 조립 함수를 사용한다. stdio 프로세스와 상주 HTTP 서비스는 각각 실행 중인 도구가 쓰는 루프백 HTTP 클라이언트를 하나씩 소유한다. 각 요청에 인증 헤더를 보내고 쿠키는 보관하지 않으며, 도구 세션이 종료된 뒤 연결 풀을 닫는다. stdio 시작에는 상주 앱이나 Keychain 어댑터가 필요하지 않다. stdout은 MCP 프로토콜 전용이다.
- 관리자 키는 Keychain, MCP 접근 토큰은 SQLite에 해시와 이름·만료·폐기·최근 사용 메타데이터로 저장한다. 원문은 발급 시 한 번 표시하고 닫기·다음 발급·해당 토큰 폐기 시 지운다. 신규 토큰은 `MCP_ACCESS_TOKEN`으로 연결하며 기존 환경 키는 조회 전용 호환 경로를 지원한다.
- MCP 토큰은 `/mcp/`와 지정된 개인 조회 경로에만 허용한다. 설정·인증 관리·근무 정정·발송 경로는 관리자 전용이다. 만료·폐기·사용 상태를 요청마다 확인한다.
- `get_my_system_status`, `get_my_today`, `get_my_workday`, `list_my_task_statuses`, `search_my_tasks`를 제공한다. 근무는 미기록·예정·실제 기록을 구별하고 메모·규칙 원문을 제외한다. 개인 업무·QA 조회는 본인 범위의 모든 원본 상태를 기본으로 포함하며 마감과 원본 키로 정렬한다. 소스 상태 목록과 검색 행에 현재 카테고리 ID와 이름을 제공한다. 검색의 `category_id`는 같은 카테고리의 본인 목록 소스를 선택하며 이름 변경 후에도 유효하다. 이전 호출의 `section` 필터는 기존 구분을 유지한다. 보드 링크 설정은 오늘 조회에서만 다시 읽는다.
- `GET /v1/tasks/statuses`는 조회 토큰에 허용한 읽기 경로로, 설정된 업무·QA 소스별 식별자와 이름, 상태 선택지, 선택지의 근거와 수집 상태를 제공한다. 스키마가 없으면 본인 행에서 관찰한 상태를 사용한다. AI는 의미로 요청한 상태를 소스별 선택지와 대조하고, 해당 `source_id`와 정확한 상태 이름을 `POST /v1/tasks/search` 본문으로 전달한다. 여러 이름은 합집합으로, 미지정은 `include_unset`으로 선택한다. 검색은 설정된 본인 조회 범위 안에서만 소스를 좁힐 수 있다.
- Codex와 Claude Code용 스킬은 개인 스킬 경로에 설치한다. 선택된 모든 대상의 기존 설치 해시를 먼저 검증한다. 내용과 권한(600)이 같은 파일은 유지하고, 설치가 실패하면 이번에 교체한 파일과 만든 빈 폴더를 역순으로 정리한다. 사용자 수정본은 보존한다. 설치는 조회 지침을 복사하며 MCP 연결 등록은 사용자가 별도로 설정한다.
- 스킬 배포 번호는 `src/infrastructure/skill_bundle.py`의 `SKILL_VERSION`에서 앱과 독립적으로 관리한다. 첫 번호는 `1.0.0`이며 동봉 지침이나 AI 메타데이터를 변경해 배포할 때 주·부·패치 번호 중 하나를 올린다. 설치 기록의 `version`은 파일 형식이고, 형식 2의 `skillVersion`은 설치한 스킬 버전이다. 형식 1은 버전 미기록으로 표시하고 다음 설치 때 기존 해시를 검증한 뒤 이전한다. MCP 설정에서 대상별 설치 버전과 업데이트 가능 여부를 확인하고 명시적으로 재설치한다. 선택한 대상 중 더 높은 버전이 있으면 모두 보존한다.

## 결과와 검증

AI에서 조회해도 수집이나 알림이 시작되지 않는다. `src/presentation/mcp.py`, `src/application/mcp_access.py`, `src/bootstrap/wiring.py`, `src/infrastructure/ai_skills.py`에서 구현한다. 만료·폐기·관리 경로 차단, stdio 호환과 스킬 재설치를 확인한다.
