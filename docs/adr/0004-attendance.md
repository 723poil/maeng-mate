# ADR 0004. 개인 근무 기록

상태: 채택

## 맥락

입력한 출근 시각과 예정 퇴근, 실제 퇴근을 각각 보존해야 한다. 사용자가 정한 규칙이 바뀌어도 이전 기록의 계산 근거를 확인할 수 있어야 한다.

## 결정

- 근무 카드에서 시·분과 휴가를 변경하면 미리보기와 자동 저장을 수행한다. 기본값은 출근이며 화면을 열기만 해서는 기록하지 않는다. 자정에는 새 서울 날짜의 미기록 상태를 읽고 이전 날짜 저장 응답을 적용하지 않는다.
- `WorkRules`와 `DeparturePolicy`를 분리한다. 설정의 **근무 규칙**에서 근무 요일, 하루 실근무 분, 출근 범위, 이른 출근 반영, 점심과 최대 네 개의 추가 휴게, 반차·반반차 차감, 오후 반차 예외를 조합한다. 추가 휴게는 `+`로 한 줄씩 추가하고 행별로 삭제한다. 고정 휴게는 시각 순서로 차감하고 겹치거나 뒤집힌 구간은 거부한다. 여러 교대조와 야간 교대 규칙은 지원 범위 밖이다.
- 새 설정은 평일 하루 8시간을 기준으로 입력한 출근 시각부터 계산한다. 출근 시각은 하루 전체 범위에서 입력할 수 있다. 점심·추가 휴게와 오후 반차의 점심 예외는 사용자가 지정할 때 적용한다. 지난 날짜는 해당 기록에 담긴 규칙으로 계산한다.
- 규칙은 Application Support의 `work-rules.json`에 포맷 버전·revision과 저장한다. 파일이 없으면 기존 SQLite 규칙을 이어받고 해당 값도 없으면 기본값을 읽는다. **기본값**은 초안만 바꾸며 저장은 명시적이다. 시작 설정과 같은 파일 읽기 경계에서 소유자·권한·크기를 확인한다. 저장할 때는 같은 디렉터리의 고정 잠금 파일을 잡은 뒤 현재 버전을 다시 읽고 권한 600으로 원자 교체한다. 같은 버전을 제출한 작성자 중 한 명만 저장되며 나머지는 충돌을 받는다. 저장 시 서울 기준 오늘 기록이 있으면 규칙만 새 버전으로 반영하고 남은 퇴근 알림을 같은 DB 트랜잭션에서 갱신한다. 파일 교체에 실패하면 트랜잭션을 롤백한다. 서비스 시작 시에도 오늘 기록을 저장된 규칙과 대조해 구버전 기록과 중단된 저장을 복구한다. 미기록 날짜는 최초 입력 시 쓰기 잠금 안에서 최신 규칙을 읽는다. 실제 출퇴근·휴가·메모·추가근무와 지난 날짜의 기록은 보존한다.
- 출근·휴가·당시 적용한 규칙·실제 퇴근·추가근무를 날짜와 revision 단위로 저장한다. 실제 퇴근 `checkoutAt`은 선택 값이다. 지난 기록에 값이 없으면 미기록으로 읽는다. 오늘 자동 저장은 이미 입력한 실제 퇴근과 추가근무를 보존한다.
- 월별 기록 창에서 실제 출퇴근을 조정하고 수정 이력을 본다. 월 목록과 달력은 저장된 행을 하나씩 검증해 만든 서울 시각 표시값을 공유한다. 상세 조회는 예정 계산과 정정에 필요한 현재 기록을 온전히 보존한다. 이력은 최신 51개 버전의 표시값을 한 번씩 만들어 인접한 버전을 비교하고 최근 50회의 변경을 보여 준다. 기록 창의 버튼과 서버는 같은 서울 날짜·예정 시각 도달 조건을 사용한다. 저장 시 서버가 읽은 버전과 기존 실제 퇴근을 다시 확인한다. 예정 옆 `확정`은 현재 버전에서 서버가 계산한 퇴근을 기록하는 별도 동작이다. 직접 조정은 시·분 입력과 저장·취소를 사용한다. 미래·익일·중복 확정은 거부하고 충돌이나 실패 시 초안을 보존한다. 관리 경로는 `/v1/work-records`다.
- 휴무일에도 출퇴근을 직접 기록할 수 있다. 예정·자동 퇴근 알림은 규칙에 포함된 근무 요일만 계산한다. 평일 야근·주말 주말근무는 같은 `overtime` 필드이며 예정 계산을 바꾸지 않는다. 목록은 토·일을 색으로 구분한다. 월간 집계는 월 목록을 새로 읽거나 저장 결과를 반영할 때 갱신한다. 창을 열어 둔 동안 퇴근 예정 시각이 지나면 확정 버튼은 계속 갱신된다.
- 근무 정정과 당일 예약 갱신은 함께 저장한다. 과거 정정은 알림을 생성하지 않고 오늘 실제 퇴근이 입력되면 남은 예약을 취소한다. [ADR 0008](0008-notification-delivery.md)

- 퇴근 예정이 서울 기준 기록일의 자정 이상이면 `overnight`로 구별한다. 출근과 계산된 익일 시각은 보존하고 미리보기·기록 상세에 익일 확정 불가와 자동 알림 미발송 이유를 표시한다. 8시간 기본 규칙에서 15:59 출근은 당일 23:59로 확정 가능하고 16:00·16:01은 익일 00:00·00:01로 확정 불가다. 휴게로 자정을 넘는 경우도 같으며, 시간이 지나거나 과거 기록이 되어도 익일 확정은 허용하지 않는다.

## 결과와 검증

조회만으로 근무 기록이나 예약이 생성되지 않는다. `src/domain/daily_work.py`, `src/application/day_records.py`, `src/application/work_records.py`, `src/infrastructure/sqlite/day_records.py`에서 구현한다. 임시 기록에서 기본 분 경계, 복수 휴게, 근무 요일 변경, 저장 충돌과 이력 보존을 확인한다.
