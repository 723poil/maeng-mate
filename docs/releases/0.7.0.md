### 새로운 기능

- 메뉴바 앱이 하루에 한 번 새 버전을 확인합니다. 업데이트가 있으면 변경 내용을 보고 설치하거나 나중으로 미룰 수 있습니다.
- 카테고리의 저장 칼럼을 골라 값 변경, 사람 추가, 날짜·시간 알림을 만들 수 있습니다. 날짜의 전날이나 당일에 받을 시각을 지정하거나, 시작 몇 분 전에 받을지 정할 수 있습니다.
- 규칙마다 보낼 문구를 쓰고 macOS 알림과 Slack DM 중 받을 채널을 선택할 수 있습니다. 퇴근 알림도 원하는 시각을 분 단위로 여러 개 지정할 수 있습니다.

### 개선 사항

- 기존 알림은 이름과 실제 칼럼 연결을 이어받아 편집 가능한 규칙으로 바뀝니다. 예를 들어 회의 시작 알림에서 기존의 10분을 원하는 시간으로 바꿀 수 있습니다. 연결된 칼럼이 없는 규칙은 이름을 보존하고 꺼진 상태로 표시합니다.

### 오류 수정

- Finder에서 앱을 연달아 열 때 시작 오류가 뜨던 문제를 고쳤습니다. 실행 중인 앱을 다시 열면 메뉴바 패널이 표시됩니다.
