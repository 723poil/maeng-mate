## 오류 수정

- 수집이 중단되어 실행권이 만료된 소스를 계속 수집 중으로 표시하던 문제를 수정했습니다.
- 설정에서 앱을 다시 시작할 때 다른 탭에서 편집 중인 알림 이름과 아이콘이 사라지지 않도록 보호했습니다.
- 수동 백업을 저장할 때 저장 위치의 파일 이름까지 동기화한 뒤 완료를 알리도록 수정했습니다. 파일은 만들어졌지만 저장 완료를 확인하지 못한 경우에는 별도로 안내합니다.
- Homebrew Python으로 개발용 앱을 실행할 때 앱이 켜져 있어도 설치·시작 준비 확인이 실패하거나 실행 중이 아니라고 표시하던 문제를 수정했습니다.
