### 새로운 기능

- **메뉴바에서 보는 오늘의 업무** — 여러 Notion 표에 흩어진 내 업무와 회의를 Mac 메뉴바에 모았습니다. 항목을 누르면 해당 Notion 페이지가 열립니다.
- **회의 시작 10분 전 알림** — 참석할 회의가 다가오면 macOS 알림이나 Slack DM으로 알려줍니다. 알림을 눌러 회의 내용을 바로 확인할 수 있습니다.
- **내 근무 규칙에 맞춘 퇴근 시각** — 출근 시각을 입력하면 휴가와 휴게 시간을 반영해 오늘 몇 시에 퇴근할 수 있는지 보여줍니다. 실제 퇴근 시각도 기록해 월별로 볼 수 있습니다.
