## 기록 방법

기획·설계·구현 계획은 결정이 확인되면 ADR로 정리한다. 기존 ADR의 주제와 겹치면 해당 문서에 근거와 최종 구현을 합친다. 독립적인 결정만 새 번호를 받아 이 표에 추가한다. 채택한 결정이 바뀌면 적용 범위와 이유를 갱신한다.

본문은 **상태 → 맥락 → 결정 → 결과와 검증** 순서로 작성한다. 실행에 필요한 제약과 구현 위치를 남기고, 작업 체크리스트·실계정 검증 기록·개인 설정값은 포함하지 않는다.
