## Codex와 Claude Code의 스킬 업데이트를 한곳에서

이제 Maeng Mate에서 두 앱에 설치된 업무 조회 스킬의 버전을 확인하고 업데이트할 수 있습니다.

**설정 → 연동 → MCP**를 열면 업데이트할 수 있는 스킬이 표시됩니다. 원하는 앱을 고르거나 **둘 다**를 선택해 한 번에 업데이트하세요. 직접 수정해 둔 스킬 파일은 그대로 보존됩니다.

**지원 환경** · Apple Silicon Mac, macOS 26 이상　[설치 안내](https://github.com/723poil/maeng-mate/blob/v0.3.0/README.md#앱-설치)
